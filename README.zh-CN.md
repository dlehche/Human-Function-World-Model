## HFWM 建模什么

HFWM 持续建模的是**同一个完整的人**，并把以下内容放进同一个纵向模型：

- 内部任务与外部任务；
- Demand；
- 所需人体功能能力；
- 当前能力；
- Actual Engagement Process；
- 人体结构与生理；
- 疾病、损伤、手术、恢复与适应；
- 表现、代价、边界和储备；
- 证据、不确定性、竞争假设与判断；
- 受治理行动与责任路由；
- 专业、照护和环境协作；
- 反馈、复评与纵向变化。

运行主线为：

```text
INTERNAL_TASK / EXTERNAL_TASK
→ Demand
→ 所需人体功能能力
→ 当前能力
→ Actual Engagement Process
→ 反应 / 表现 / 代价 / 边界 / 恢复
→ 证据 / 假设 / 不确定性
→ 判断
→ 受治理行动 / 责任路由
→ 实际变化
→ 反馈 / 复评
→ 纵向更新
```

UOHF 根定义仍然优先于这条运行链。Task 用于使 Demand 明确，而不是用 Task 替代人体功能根定义中的内部与外部需求。

## 历史来源

“Human Function World Model（HFWM）”这一术语已经由同一作者于 2026 年 7 月 15 日在 **UOHF Definition 2.0** 中公开披露。该文区分 UOHF、Individual Human Function Model 与 HFWM，并把 HFWM 描述为加入时间、行动、状态转移、预测和记忆回写的世界模型层。

UOHF Definition 2.1 随后恢复内部与外部需求的完整根范围。

本仓库用于把 HFWM 从单篇论文中的架构层，发展成可以长期扩展的独立公开研究体系。

## 18 项核心能力 + 104 项具体能力

HFWM 使用公开 UOHF 人体功能能力体系作为受治理的人体功能坐标。

当前第一版：

- **18 项核心人体功能能力**
- **104 项具体人体功能能力**

HFWM 不重复建立第二份 104 项正式定义，UOHF 继续承担这些能力对象的语义权威。

见 [`capacity-coordinate/README.zh-CN.md`](capacity-coordinate/README.zh-CN.md)。

## Functional Bridge

Functional Bridge 是 HFWM 周围的受治理**知识关系层**，用于把人体功能能力继续连接到：

- 解剖结构与空间组织；
- 生理与生物过程；
- 跨能力组织；
- 反应；
- 状态、时间与变化；
- 证据与推断边界。

它不是 A14，不是第二套本体，不替代 UOHF 正式关系，也不能直接成为某个具体人的证据、诊断、病因或行动处方。

公开科学参考可包括：

- **Human Reference Atlas（HRA）**：结构与空间参考；
- **NIH Whole Person Reference Physiome（WPP）**：跨器官、跨系统、跨尺度生理参考；
- 其他来源、版本、许可与语义范围明确的受控科学来源。

见 [`functional-bridge/README.zh-CN.md`](functional-bridge/README.zh-CN.md)。

## “完整的人”是什么意思

“完整的人”不等于已经模拟人体所有分子、细胞、全部生物变量、社会变量和所有未来。

它强调：

> 无论进入生理、医学、人体功能、物理治疗、作业治疗、言语语言治疗、听力、营养、心理、运动、家庭或现实生活环境，持续被建模的始终是**同一个人**。

疾病、损伤、感染、手术和人体自身状态变化可以**触发内部任务**，但不能被静默等同为 Task 或 Demand。

---

## 医学 ⇄ 人体功能

HFWM 强调医学与人体功能双向进入，但不能互相等同。

医学事实可以改变安全边界、人体结构与生理条件、当前能力、实际调用、恢复和现实任务承担。

反过来，新的进行性功能变化、异常恢复、无法解释的功能下降，也能够形成“需要重新进入医学系统”的治理化问题。

HFWM 不把人体功能证据自动转换成医学诊断。

---

## 围绕同一个人的协作

HFWM 可以表达医生、护士、物理治疗师、作业治疗师、言语语言病理学家/言语语言治疗师、听力师、营养师、心理专业人员、运动训练专业人员、合资格按摩/手法相关从业人员，以及本人、家庭、照护者、辅助技术和环境调整之间的动态协作。

共同对象始终是同一个人，不同专业继续保留各自权限、证据要求和专业边界。

---

## 身体功能报告

身体功能报告不是世界模型本身，而是：

> **在指定时间、指定证据、指定受众和指定权限下，对当前证据支持世界状态形成的人类可读投影。**

历史报告必须可以按当时状态回放，不得被后续数据静默改写。

---

## 当前边界

当前公开 HFWM 框架已经形式化规定：

- 完整人状态表示；
- 内部/外部任务及 Demand；
- 人体功能能力与实际调用；
- 证据、不确定性、假设和判断；
- 受治理下一步与责任路由；
- 反馈、复评和纵向更新；
- 人类可读状态投影；
- 受治理科学知识连接。

当前不宣称：

- 已经穷尽模拟完整人体；
- 已经验证所有未来状态预测；
- 已经完成任意干预的因果反事实模拟；
- 能自主医学诊断；
- 能自主完成高风险治疗决策；
- 已经完成全部临床结局验证；
- 已经公开完整生产推理系统。
