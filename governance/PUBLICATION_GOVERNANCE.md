# Publication Governance

Each public HFWM publication should record:

- exact title;
- author(s);
- date;
- status;
- version/revision if the publication itself uses one;
- DOI/arXiv/archival identifier when registered;
- license;
- source path;
- relation to earlier/later publications;
- claim boundary.

Reserved or planned identifiers must never be described as already registered.

Historical publication wording must not be silently rewritten in citations.

`PUBLICATIONS.json` is the machine-readable publication map for this repository.
