# HFWM Governance

HFWM public governance is designed to prevent semantic drift, authority collapse and accidental disclosure of production implementation.

## Authority order

1. Canonical UOHF definitions govern the meaning of human function and UOHF objects.
2. Dedicated HFWM publications govern HFWM-specific whole-person world-model claims.
3. Public architecture documents explain the HFWM research structure but do not override a canonical publication.
4. Functional Bridge public documents govern knowledge-relation boundaries but do not create formal UOHF relations.
5. Examples and benchmarks are non-normative unless explicitly promoted through governance.

## Change principles

- preserve historical versions;
- do not silently rewrite published claims;
- keep publication status separate from production-runtime status;
- keep knowledge separate from person-specific evidence;
- explicitly record uncertainty and unresolved conflicts;
- do not publish private implementation merely to make public documentation look complete.
