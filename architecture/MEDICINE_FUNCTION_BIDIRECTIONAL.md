# Bidirectional Medicine–Human-Function Reasoning

HFWM connects medicine and human function bidirectionally without collapsing one into the other.

## Medicine → human function

Medical evidence may constrain:

- safety;
- structural and physiological conditions;
- current human-function capacity;
- engagement boundary;
- recovery;
- task feasibility;
- admissible action.

## Human function → medicine

New or progressive functional change can generate a governed medical question or escalation need when:

- a previous functional explanation no longer explains the observed change;
- deterioration is rapid, progressive or unexplained;
- recovery is abnormal;
- new safety signals appear;
- required evidence lies outside the current professional scope.

## Boundary

Functional change is not an autonomous medical diagnosis. Medical escalation is a governed next action, not a diagnosis generated from human-function evidence alone.
