# Internal and External Tasks

HFWM represents both internal and external task contexts.

## External tasks

Examples include self-care, mobility, work, communication, family responsibilities, exercise, sport and social participation.

## Internal tasks

Internal tasks can include maintenance, regulation, defense, hemostasis, damage control, repair, recovery, adaptation, sleep–wake regulation, growth/development and other governed internal requirements.

## Critical boundary

Disease, injury, infection, surgery or endogenous state change may **trigger** one or more internal tasks. They are not silently converted into a Task or Demand merely because they exist.

The governed operational sequence is:

```text
INTERNAL_TASK / EXTERNAL_TASK
→ Demand
→ Required Human-Function Capacity
→ Current Capacity
→ Actual Engagement Process
→ Response / Cost / Boundary / Recovery
→ Evidence / Judgment
→ Governed Action
→ Feedback / Reassessment
```

The UOHF root definition still has priority: human function is the body's capacity to be appropriately engaged to meet internal and external demands.
