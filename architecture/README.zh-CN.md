# HFWM 公开总体架构

[English](README.md)

HFWM 严格区分公开科学架构与私有生产实现。

## 当前公开层次

1. **语义基础**：UOHF 定义、身份、类型、关系、证据与治理边界。
2. **人体功能能力坐标**：公开 18 项核心 + 104 项具体能力体系。
3. **知识关系层**：Functional Bridge，在保留来源边界的前提下连接外部科学资源。
4. **个体状态层**：同一个人的纵向世界状态与历史。
5. **证据层**：自述、观察、测量、系统计算、专业确认等。
6. **推理层**：任务、Demand、所需能力、当前能力、实际调用、竞争假设、不确定性与判断。
7. **行动治理层**：安全、专业权限、可执行性、责任路由、停止与复评条件。
8. **纵向更新与投影层**：反馈、复评、历史保留更新和身体功能报告。

## 公开架构硬边界

- 人体功能是独立于医学而客观存在的身体能力现实；HFWM 表示人体功能，但不创造人体功能。
- 同一个完整的人是持续建模主体；人体功能是统一组织坐标，但不是人的全部，也不是世界模型的建模边界。
- 医学—人体功能关系目的上不对称、运行上双向：医学最终服务于人，并在身体层面服务人体功能；人体功能变化持续为医学提供问题、目标、边界和反馈。
- 疾病/损伤可以触发内部任务，但不能自动等同任务。
- 一般科学知识不等于个体证据。
- 实际调用过程、证据断言和调用模式推断必须分开。
- 医学事实保留医学身份；人体功能证据不能自主变成医学诊断。
- 专业路由不能取消专业权限。
- 报告投影不是第二套事实源。
- 预测、观察更新和因果结论必须分开。
