# HFWM Public Architecture

HFWM separates public scientific architecture from private production implementation.

## Core public layers

1. **Semantic foundation** — UOHF definitions, identities, types, relations, evidence and governance boundaries.
2. **Human-function capacity coordinate** — public 18 core + 104 specific capacity system.
3. **Knowledge-relation layer** — Functional Bridge, with provenance-preserving connections to external scientific resources.
4. **Person-state layer** — the same person's longitudinal modeled state and history.
5. **Evidence layer** — observed, reported, measured, derived and professionally confirmed evidence.
6. **Reasoning layer** — task, Demand, required capacity, current capacity, actual engagement, hypotheses, uncertainty and judgment.
7. **Action-governance layer** — safety, authority, feasibility, responsibility routing, stop and reassessment conditions.
8. **Longitudinal update and projection layer** — feedback, reassessment, history-preserving update and human-readable reports.

## Architectural constraints

- Human function is the organizing coordinate, not the modeled-world boundary.
- Disease/injury may trigger internal tasks but are not automatically tasks.
- General scientific knowledge is not person-specific evidence.
- Actual Engagement Process, evidence-bearing Functional Engagement Assertion and Engagement-Pattern Inference remain distinct.
- Professional routing does not erase professional scope or authority.
- Report projection does not become a second source of truth.
- Prediction claims remain separated from observed state update and causal attribution.
