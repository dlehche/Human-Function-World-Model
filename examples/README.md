# HFWM Non-Normative Examples

Examples in this directory are explanatory and non-normative unless explicitly identified otherwise.

Planned public examples include:

1. **External task:** stair negotiation with pain or instability.
2. **Internal task:** infection, defense and recovery.
3. **Post-discharge transition:** medical stability → functional restoration → life return.
4. **Responsibility re-routing:** new medical risk during long-term maintenance.
5. **Longitudinal projection:** historical Body Function Reports without retrospective rewriting.

Every example must preserve the distinction among general knowledge, person-specific evidence, hypothesis, judgment, action and outcome.
