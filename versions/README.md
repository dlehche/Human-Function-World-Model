## Governance rule

Each future public release should record:

- public date;
- exact artifact;
- DOI/arXiv identifier if registered;
- license;
- scientific/documentary/machine-readable change type;
- relationship to previous versions.

Production-runtime versions belong to separate governance and are not inferred from public repository versions.
