# 全球首个基于人体功能统一本体（UOHF）、以“完整的人”为持续建模对象的人体功能世界模型，正式灰度上线

**发布日期：2026-10-02**

**English announcement:** [The World’s First Human Function World Model Built on UOHF, with the Whole Person as the Persistent Modeling Object, Enters Gray Release](2026-10-02-movetips-hfwm-gray-release.en.md)

木梯人体功能（MoveTips Human Function）现已正式进入产品灰度运行阶段。

这是 UOHF 从人体功能根定义、统一语义、本体关系、形式化框架与人体功能世界模型，进一步进入真实产品运行的重要里程碑。

木梯人体功能以**同一个“完整的人”**为持续建模对象，以**人体功能统一本体（UOHF）**作为语义与计算基础，将就医、康复、运动、营养、心理以及日常身体变化持续连接到同一个人的人体功能状态中。

产品通过身体功能报告持续呈现和更新人体功能状态，不只是记录“发生了什么”，而是尝试在证据、任务需求、人体功能能力、实际功能调用、行动与纵向变化之间建立可追溯关系，进一步解释：

> **为什么这些变化最终在这个人身上形成了当前问题。**

其目标不是把不同领域的数据简单堆叠在一起，而是在保留医学、康复、运动、营养、心理等专业边界的前提下，让不同来源的事实、评估、行动、结果和时间变化能够在统一的人体功能语义下持续连接、追踪和更新。

## Product milestone

MoveTips Human Function has entered a public gray-release stage.

The product is built on the **Unified Ontology of Human Function (UOHF)** and uses the **same whole person as a persistent modeling object**. It connects medical care, rehabilitation, exercise, nutrition, psychology, and everyday bodily changes through a shared human-function semantic and computational framework.

Rather than treating these domains as disconnected records, the Human Function World Model is designed to represent evidence, task demand, functional capacities, actual functional engagement, governed actions, feedback, and longitudinal change around the same person over time.
