# The World’s First Human Function World Model Built on UOHF, with the Whole Person as the Persistent Modeling Object, Enters Gray Release

**Release date: 2026-10-02**

MoveTips Human Function has officially entered its product gray-release stage.

This marks an important transition from the Unified Ontology of Human Function (UOHF), the formal human-function framework, and the Human Function World Model into a running product.

## The whole person is the modeling object

The central idea is not to build separate models for separate domains.

MoveTips Human Function uses **the same whole person as the persistent modeling object**.

Built on the **Unified Ontology of Human Function (UOHF)**, the Human Function World Model continuously connects medical care, rehabilitation, exercise, nutrition, psychology, and everyday bodily change back to the same person and the same evolving human-function state.

The model does not merely record what happened. Through longitudinal human-function reports, it is designed to connect evidence, task demands, required functional capacities, actual functional engagement, actions, outcomes, and change over time in order to address a more fundamental question:

> **Why did these changes, in this whole person, ultimately form the current problem?**

The goal is not to collapse medicine, rehabilitation, exercise, nutrition, psychology, and daily life into one undifferentiated dataset. Each domain retains its own professional meaning and boundaries. UOHF provides the shared semantic and computational foundation that allows their relevant facts, assessments, actions, outcomes, and longitudinal changes to be connected around **one whole person**.

## From ontology to a running world model

The product path is:

> **UOHF → governed human-function semantics → Human Function World Model → the same whole person over time → continuous evidence, state, action, feedback, and update**

This is what distinguishes the model from a collection of disconnected health records or one-time reports.

The modeling object remains the same person before illness, during medical care, through rehabilitation, during exercise and daily life, and as new changes emerge over time.
