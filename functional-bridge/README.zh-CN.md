# HFWM 中的 Functional Bridge

Functional Bridge 是连接人体功能与解释性科学知识的受治理**知识关系层**。

它可以公开研究：

- 解剖实现与支持；
- 空间组织；
- 生理和生物过程；
- Demand 相关性；
- 跨能力组织；
- 反应；
- 状态/时间/变化；
- 证据与假设边界；
- 干预上下文。

Functional Bridge 不是 UOHF A14，也不是第二套本体。

一般科学命题即使来源可靠，也不会自动成为某个具体人的事实、病因、诊断或行动依据。

公开科学参考可以包括：

- **Human Reference Atlas（HRA）**：人体解剖、细胞类型、生物标志物和空间组织参考；
- **NIH Whole Person Reference Physiome（WPP）**：多器官、多系统、多尺度生理整合参考；
- 其他来源、许可和语义范围明确的受控科学资源。

本仓库不会因为公开 Functional Bridge 研究，就自动公开私有来源映射、完整关系库存、覆盖账本、检索/重排实现、Prompt、决策权重或生产推理逻辑。
