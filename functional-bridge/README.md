# Functional Bridge in HFWM

Functional Bridge is a governed **knowledge-relation layer** connecting human-function capacities to explanatory scientific knowledge.

It can organize scientific propositions about:

- anatomical realization and support;
- spatial organization;
- physiological and biological processes;
- Demand relevance;
- cross-capacity organization;
- response;
- state/time/change;
- evidence and hypothesis boundaries;
- intervention context.

## Not an ontology layer

Functional Bridge is not UOHF A14 and is not a second ontology.

## Not individual evidence

A bridge proposition does not become a person-specific fact merely because it is scientifically plausible or well sourced.

## Reference resources

Public reference resources can include:

- **Human Reference Atlas (HRA)** for anatomy, cell types, biomarkers and spatial organization;
- **NIH Whole Person Reference Physiome (WPP)** for multiorgan and multiscale physiological integration;
- other controlled scientific sources when provenance, licensing and semantic scope are explicit.

## Governance path

```text
Scientific source
→ source-bounded proposition
→ Functional Bridge knowledge unit
→ scientific review / provenance / boundary
→ retrieval and explanation support
```

This path does **not** automatically continue to:

```text
→ Formal UOHF relation
→ person-specific Evidence
→ diagnosis
→ action prescription
```

Those transitions require separate governance and evidence.

## Public/private boundary

This repository can publish the scientific role, public examples, source references and research methods of Functional Bridge. It does not automatically publish private source maps, complete relation inventories, coverage ledgers, retrieval/reranking implementation, prompts, decision weights or production reasoning logic.
