# HFWM Public Status

## Current status

HFWM is in active scientific and computational development.

Publicly established components include:

- UOHF semantic foundation;
- public 18-core/104-specific human-function capacity coordinate;
- typed capacity/engagement distinction;
- internal/external task and Demand architecture;
- evidence-constrained reasoning;
- bidirectional medicine–human-function framing;
- public Functional Bridge role and governance boundary;
- professional/life coordination model;
- longitudinal state update;
- Body Function Report as a governed projection;
- **HFWM Version 1.0 Zenodo publication — DOI 10.5281/zenodo.22685308**;
- **human-model interoperability Version 1.0 — DOI 10.5281/zenodo.23180973**.

## Repository role

This repository is the canonical public GitHub home for HFWM-specific architecture, publications, model interoperability, Functional Bridge, longitudinal modeling, public benchmarks, examples, and HFWM governance.

UOHF remains the semantic authority for the definition of human function, ontology identities, and governed UOHF relations.

## Not yet claimed complete

- clinical outcome validation;
- calibrated general future-state prediction;
- causal counterfactual intervention planning;
- universal professional-routing validation;
- complete Functional Bridge public coverage;
- full public machine-executable HFWM release.

Publication status and production-runtime status are governed separately.
