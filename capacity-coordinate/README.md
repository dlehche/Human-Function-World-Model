# HFWM Human-Function Capacity Coordinate

HFWM uses the public UOHF capacity system as its governed human-function coordinate.

Current public Version 1.0:

- **18 core human functional capacities**
- **104 specific human functional capacities**

Canonical public source:

- [The UOHF Human Function Capacity System](https://github.com/dlehche/Unified-Ontology-Of-Human-Function/tree/main/papers/capacity-system)

HFWM does not duplicate the complete 104-capacity definitions. UOHF remains the semantic authority for those objects.

The capacity catalogue answers:

> What stable whole-person human-function capacities can be referenced?

HFWM then asks:

> Which capacities are required now, which are currently available, how are they actually engaged, and how do those facts change over time?

See [`CORE_CAPACITY_MAP.md`](CORE_CAPACITY_MAP.md).

The complete production Demand→Capacity matrix is outside the public release boundary.
