# HFWM 人体功能能力坐标

HFWM 使用公开 UOHF 人体功能能力体系作为受治理的人体功能坐标。

当前公开第一版：

- **18 项核心人体功能能力**
- **104 项具体人体功能能力**

权威公开来源：

- [UOHF 人体功能能力体系](https://github.com/dlehche/Unified-Ontology-Of-Human-Function/tree/main/papers/capacity-system)

HFWM 不在本仓库重复维护 104 项能力的第二份正式定义，UOHF 继续负责这些对象的语义权威。

能力目录回答：

> 完整的人有哪些可以被规范引用的稳定人体功能能力？

HFWM 继续回答：

> 现在需要哪些能力？当前可用多少？实际怎样调用？这些事实怎样随时间变化？

完整生产 Demand→Capacity 需求矩阵不属于本公开仓库的发布内容。
