# 14. 身体功能报告：世界模型状态面向人的投影

身体功能报告不是世界模型状态本身，而是某一个时间点，在明确证据和权限条件下，面向特定受众生成的“当前模型状态的人类可读投影”。形式上可以写为：

**Report_t = Projection(ModelState_t, Evidence_t, Audience, Authority, Version)**

这个边界能够避免报告变成第二套事实源。世界模型内部可以保留潜在假设、未确认信息、历史版本、机器级来源和不适合某类受众直接看到的信息；面向本人的报告则应以可理解语言说明当前人体功能状态、主要表现、真正有意义的变化、当前功能边界、下一步以及后续观察条件。专业端投影可以进一步显示判断依据、证据链、不确定性、风险边界、未回答问题和复评条件。

连续、不可变的报告快照在深层世界模型之上形成一条可理解的纵向表面。其价值不仅是“有一份报告”，而是让本人、家庭和多个专业角色能够在同一个当前状态上对齐，理解为什么责任角色或行动发生变化，并把疾病、治疗、出院、恢复、长期维护和未来新事件连接成同一个人的历史。

不同专业不需要看到完全相同的内容。医生、物理治疗师、作业治疗师、言语语言治疗师/言语语言病理学家、听力师、营养师、心理学家或心理治疗师、运动训练专业人员和本人可以拥有不同视图，但这些视图必须指向同一个人、同一份证据快照和同一个版本化世界状态。

# 15. 完整案例

## 15.1 内部任务案例：感染后的防御与恢复

一个人发生急性感染。感染属于医学事件和病理背景，不是内部任务本身。在相应受治理任务身份与触发规则已经成立时，它可以激活防御、免疫调节、体温调节、循环与能量分配、组织保护、恢复和稳态恢复等内部任务。证据可以来自症状、体温、实验室或临床结果、睡眠、食欲、疲劳、心肺反应和恢复轨迹。同时，这个人的工作和移动外部任务可能被迫降低。HFWM 同时表示两类任务，保留医学权限，并根据安全与证据把行动从观察、休息、补证据一直路由到必要的医学升级。

## 15.2 出院案例：从医学稳定到恢复真实生活

一个人在手术后出院。出院只能说明住院医学阶段达到某个转折点，并不能证明人体功能已经完整恢复。这个人仍然可能存在修复与恢复的内部任务，同时面临翻身、转移、穿衣、洗澡、进食、行走、上下楼、交流、工作、照顾家庭和重新运动等外部任务。物理治疗师可能主导移动和负荷相关恢复；作业治疗师可能主导自我照护、家庭活动、工作角色和环境适配；护士可能继续承担创面与护理连续性；营养师可能针对摄入与恢复提供专业支持；心理治疗师或心理学家可在心理、认知—情绪—行为因素成为重要限制时进入；出现吞咽、语言或沟通问题时可由言语语言治疗师/言语语言病理学家进入，出现听觉问题时可由听力师进入。主导角色可以变化，但这个人的模型不更换。

## 15.3 重新路由案例：长期维护中出现新风险

一个原本长期运动维护稳定的人出现新发进行性无力，并且原本稳定的现实任务快速下降。HFWM 不应把这简单解释成“训练执行差”或普通能力波动。新的事实削弱旧模型，形成安全相关证据缺口，并把责任重新路由回医学评估。新的医学证据回来以后，再继续判断下一阶段是医学处理、物理治疗、作业治疗、其他专业、调整运动还是观察。

# 16. 为什么 HFWM 是 World Model，而不是普通知识库或决策系统

| 世界模型必要能力 | HFWM 的承载方式 | 当前证据状态 |
|---|---|---|
| 状态 | 版本化完整人状态及其证据支持表示 | 已完成形式化定义 |
| 观察 | 本人报告、专业观察、测量、设备和正式记录 | 已完成形式化定义 |
| 记忆 | 纵向历史、旧状态、行动、反应和未解决不确定性 | 已完成形式化定义 |
| 动态 | 内部/外部任务、内源调节、环境和行动下的真实变化 | 已定义形式化状态转移结构；尚未完成经验校准 |
| 行动条件化 | 受治理行动会改变未来状态或信息 | 已定义并受治理约束 |
| 不确定性 | 明确未知、竞争性假设、证据状态 | 已完成形式化定义 |
| 规划 | 选择并路由当前最合适的下一步行动 | 部分成立：支持受治理的下一步选择/责任路由，不等于最优规划 |
| 更新 | 反馈与复评修正模型但保留历史 | 已定义并要求保留历史 |
| 预测 | 潜在/预测结果与观察结果分开；校准预测属于分阶段研究目标 | 作为独立对象被表示；本文不声称已完成经验验证 |

*表 4｜HFWM 为什么超过静态本体、普通记录系统、报告生成器或普通问答模型。*

UOHF 提供世界的语义坐标系；HFWM 在这个坐标系上持续维护一个具体人的状态、行动和变化。两者的关系类似于：一个负责定义这个世界里有哪些对象与关系，另一个负责维护“这个具体世界实例现在是什么、发生了什么、下一步可能怎样变化”。

# 17. 不泄露商业秘密的实现导向架构

公开论文可以描述 HFWM 的功能层，而不需要公开木梯真实生产实现。最低层级可以包括：①受治理语义层：Person、Task、Demand、人体功能能力、调用、证据、状态、行动与溯源；②版本化人体功能能力坐标系：当前公开为 18 项核心能力 + 104 项具体能力[12]；③受治理知识关系层 Functional Bridge：在保持来源和推断边界的前提下，把能力连接到 HRA 等解剖/空间参考知识[13]、WPP 等多尺度生理参考知识[5,6]以及其他受控科学来源；④版本化个体状态与纵向记忆层；⑤证据层；⑥人体功能推理层；⑦安全、权限与责任路由层；⑧纵向更新与报告投影层。

本文有意不公开生产提示词、Provider 选择、上下文压缩、私有检索/重排逻辑、完整私有关系清单、数据库结构、计费规则及其他并非评估科学框架所必需的商业实现细节。学术可复现性应集中在公开定义、形式对象、示例案例、基准任务和版本化公开 UOHF 资源。

# 18. 形式化需求追踪、能力案例分析与经验研究计划

## 18.1 需求追踪设计

本文针对第 16 节定义的世界模型必要能力和第 15 节代表性案例进行形式化需求追踪分析。分析检查框架是否为状态、观察、记忆、动态、行动条件化、不确定性、规划/路由、更新与预测提供明确的类型承载和治理规则，并检查代表性案例能否在不把疾病混成任务、不把过程混成推断、不把功能证据混成诊断、不把责任路由混成越权行动的前提下完整通过。该分析属于架构与语义分析，不是临床结局试验，也不是经校准的 Runtime 预测基准。

| 评估项 | 结果 | 解释 |
|---|---|---|
| 状态、观察、记忆、不确定性、更新 | 已满足｜形式规范层 | 已定义明确类型、来源、版本和保留历史的更新规则。 |
| 行动条件化 | 已满足｜形式规范层 | 受治理行动与人体实际调用保持分型，并受证据、安全、权限与复评约束。 |
| 动态 | 已满足｜形式架构层 | 已经定义真实状态转移结构，但不宣称该转移函数是经过校准的万能人体方程。 |
| 规划 | 部分满足 | 支持受治理的下一步选择与责任路由；尚未建立最优多步规划。 |
| 预测 | 尚未经验验证 | 潜在/预测结果被独立表示，但本文不把校准未来状态预测作为已经成立的经验结论。 |

## 18.2 代表性案例能力检验

第 15 节三个案例被作为语义与权限一致性的能力检验，而不是作为流行病学样本。检验目标是确认框架在差异明显的情境中仍然保持同一套类型、证据和权限边界。

| 案例 | 检验重点 | 结果 |
|---|---|---|
| 感染后的防御与恢复 | 医学事件与受治理内部任务保持区分；内部任务形成/追溯 Demand；保留医学权限。 | 符合 |
| 出院后恢复真实生活 | 在内部恢复任务、外部生活任务及多个专业角色变化时仍保持同一个人的连续身份。 | 符合 |
| 长期维护中新风险重新路由 | 新证据能够削弱旧模型并触发医学复评，而不会自动形成疾病诊断。 | 符合 |

需求追踪分析表明，该框架在形式架构层已经明确承载大部分既定世界模型要求；规划仍为部分能力，预测仍未经过经验验证。这些结果不证明临床有效性、预测优越性或无人监督部署的安全性。

## 18.3 后续经验研究计划

- 语义有效性：专业人员能够稳定区分任务、需求、能力、实际调用、表现、证据、假设、行动和状态。
- 任务—需求有效性：内部和外部任务能够形成可辩护的需求规范和所需人体功能集合。
- 证据纪律：系统能够保留证据不足，避免症状→病因、结构→病因、测试异常→主原因的越级推断，并明确下一步缺什么证据。
- 专业/生活路由有效性：下一步由哪个专业、本人、照护者或环境行动进入，符合证据、安全、权限和现实范围。
- 纵向一致性：新证据可以更新模型，但不会覆盖历史状态，也不会虚构没有观察到的连续性。
- 决策效用：与更简单基线相比，模型引导的下一步在安全、效率、信息增益、连续性或人体功能结果上有更好表现。
- 报告效用：本人和专业视图能够改善理解、交接和连续服务，同时保持证据边界。
- 预测有效性：当未来形成校准模型后，结构化 HFWM 状态在恶化、恢复、升级转介、任务持续或干预反应预测上优于简单变量。
- 泛化能力：同一核心架构可以覆盖内部需求、日常生活、沟通、移动、工作、运动、衰老、疾病事件和不同专业场景。

建议建立分级能力路线：HFWM-L1＝完整人状态表示；HFWM-L2＝证据约束推理与责任路由；HFWM-L3＝经过验证的状态转移预测；HFWM-L4＝具有因果依据的反事实模拟与规划。任何实现都不应仅因为叫 HFWM 就默认已经达到 L4。
