# 19. 可证伪性与失败条件

- 如果在严格研究中能力和实际功能调用无法被可靠区分，两轴结构的实证价值需要被收缩。
- 如果内部任务建模相对于普通生理/医学状态描述没有增加解释、预测或决策价值，应缩小该扩展。
- 如果专业路由不能在保持安全与权限的前提下优于简单转介规则，其复杂性缺乏依据。
- 如果纵向更新会覆盖历史，或者不能说明为什么模型状态发生改变，World Model 主张会被削弱。
- 如果面向本人的身体功能报告经常偏离证据支持的模型状态，投影层失败。
- 如果模型系统性地把表现、结构或测试结果直接写成病因或诊断，治理失败。
- 如果模型无法保留明确未知，它就不是证据约束的完整人模型。
- 如果未来预测能力不能超过更简单的基线，应拒绝或修正相应预测扩展。

# 20. 讨论

## 20.1 人体功能为什么可以成为完整人的统一运行坐标

HFWM 认为，不需要把所有专业知识强行合并成一个学科，也可以持续建模同一个完整的人。人体功能之所以适合作为统一运行坐标，是因为每一个活着的人都必须不断满足生命内部需求，同时又必须完成现实生活外部需求。结构、生理、疾病、心理、营养、环境和专业行动，一旦回到“这个人现在必须做什么、能做什么、实际怎么做、后来变成什么”这一主线，就获得了共同位置。

## 20.2 HFWM 远不只是医学模型

医学非常重要，但 HFWM 不是只在医疗系统里存在的世界模型。它跟随同一个人从没有疾病的时候，到疾病和治疗，到出院后的恢复，再到物理治疗、作业治疗、沟通或吞咽服务、听觉服务、营养和心理支持、运动训练、自我管理、家庭生活、工作、衰老和新的健康事件。真正连续的是这个人，而不是某一个专业服务。

## 20.3 不是还原主义

“通过人体功能建模完整的人”不意味着人的每一个属性都是人体功能。HFWM 建模的是这个人的身体如何维持生命、完成任务和在世界中行动，并在必要时把价值、偏好、关系、环境和专业条件作为上下文进入。这个边界既保护科学清晰性，也避免把“完整的人”缩成单一功能主义。

## 20.4 与 WPP 和 VHT 的长期关系

WPP 与欧洲 VHT 已经说明国际研究正在向跨尺度、个体化和完整人模型推进[5-10]。HFWM 提供的是另一个重要组织层：内部/外部任务、需求约束的人体功能能力、实际功能调用、专业与生活路由以及行动—反馈纵向更新。长期方向应是互操作，而不是划地盘式竞争。

# 21. 局限

- 本文报告了形式一致性评估和代表性能力案例，但仍不是临床验证研究、临床结局基准或经过校准的预测模型评估。
- 完整人建模不等于已经穷尽模拟全部生物变量，很多状态仍然是潜在或未建模的。
- 当前 UOHF 人体功能能力目录与关系拓扑仍是版本化科学资产，未来可以演化。
- 专业执业范围因国家、地区和机构不同而变化；HFWM 的路由不能创造法律权限。
- 因果结论需要合适证据与研究设计；行动后改善不能证明唯一原因。
- 预测与反事实能力需要经过校准的纵向和干预数据，本文架构本身不自动意味着这些能力已经成立。
- “全球首款”优先权主张具有暂时性，如发现更早等价工作应更新。
- 本研究来自同时开发相关软件、本体、培训和服务的机构，需要独立外部验证。

# 22. 结论

人体功能世界模型把同一个完整的人作为持续建模主体，以人体功能作为统一组织坐标。在当前运行层中，生命维持、防御、修复、恢复和适应等内部目标通过受治理的内部任务表示进入并产生 Demand；自我照护、沟通、移动、工作、家庭生活、社会参与和运动等外部任务形成相应 Demand。HFWM 把结构与生理、疾病与损伤、功能能力与实际调用过程及其证据断言、证据与不确定性、医学与人体功能复评、专业服务与自我管理及环境、行动与反馈、当前状态与纵向变化连接起来。

本文的核心主张不是“一条方程已经算完完整人体”，而是：一个统一、证据约束、可版本化的世界模型架构，可以在不同生物尺度、不同专业、不同生活环境、不同时间点进入时，始终保留同一个完整的人。人体功能仍然是身体为满足内部和外部需求而能够被适当调用的能力；HFWM 以这一以能力为语法中心的概念作为统一运行坐标，持续建模同一个完整的人如何维持生命并生活于世界。

如果经过验证，HFWM 可以成为从疾病和医学治疗到出院、恢复真实生活、物理治疗、作业治疗、沟通与听觉服务、营养与心理支持、运动、长期维护以及未来新健康事件之间的共享计算基础，同时不把这些领域合并成一个专业，也不把完整的人压缩成一个单一指标。
