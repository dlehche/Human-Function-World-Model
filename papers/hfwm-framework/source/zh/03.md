# 9. 医学—人体功能双向推理

## 9.1 医学 → 人体功能

医学信息以有类型的证据和上下文进入 HFWM。诊断、疾病阶段、损伤、手术、药物、影像、实验室结果、医学限制、危险信号和医学许可可以约束内部任务、能力、安全边界和允许行动。HFWM 继续回答：这些医学事实对于同一个人维持生命、恢复、移动、进食、交流、工作、运动和参与现实生活到底意味着什么。

## 9.2 人体功能 → 医学

反方向同样重要。原本稳定的人体功能突然快速下降、进行性无力、恢复持续异常、任务耐受出现无法解释的变化，或者当前人体功能假设已经无法解释新变化时，都可以形成受治理的医学问题。HFWM 不能把这些信号自动写成疾病诊断，而是形成重新医学评估的需要，保留现有证据与不确定性，等新的医学证据回来以后再更新同一个人的模型。

## 9.3 边界

医学与人体功能是双向进入，但不是互相等同。医学诊断不是人体功能判断，人体功能变化也不是疾病诊断。两者之间必须经过证据、安全、专业权限和执业范围。

```text
医学证据
→ 内部任务 / 安全 / 能力
→ 人体功能状态
→ 异常变化 / 证据缺口
→ 医学问题 / 转介
→ 新医学证据
```

# 10. 围绕完整人的协作拓扑

HFWM 不只是医学协作模型。同一个人的状态可能需要专业服务、照护、自我管理、运动、营养、心理、家庭、辅助技术和环境共同参与。协作拓扑是动态的：谁主导、谁补充证据、谁可以行动、什么时候交接，取决于当前主问题、任务、证据、风险、专业权限和当前阶段。

| 参与者 / 系统 | 在 HFWM 中的典型作用 |
|---|---|
| 医生 | 医学诊断、稳定性、疾病/损伤处理、医学限制与升级处理 |
| 护士 | 临床观察、护理连续性、创面/长期护理、教育及护理专业范围内的执行 |
| 物理治疗师（Physical Therapist；部分地区称 Physiotherapist） | 移动、运动相关能力、负荷、现实任务回归与身体功能恢复 |
| 作业治疗师 | 自我照护、家庭活动、工作角色、参与、环境与辅助技术适配 |
| 言语语言治疗师/言语语言病理学家 | 语言、言语、沟通、吞咽及相关任务 |
| 听力师 | 听觉功能评估与管理 |
| 营养师（Dietitian） | 营养风险、摄入、物质和能量条件、恢复与适应支持 |
| 心理学家 / 心理治疗师 | 心理健康、认知—情绪—行为因素及相应专业干预 |
| 运动训练专业人员 | 长期能力维护与发展、负荷进阶、运动表现和边界扩展 |
| 按摩 / 手法相关专业人员 | 在当地法律、资质和证据允许范围内提供相关服务 |
| 本人、家庭与照护者 | 目标与偏好、自我管理、日常观察、协助、依从与真实生活条件 |
| 环境与技术 | 家庭/工作/学校/社区条件、辅助器具、无障碍与任务条件调整 |

*表 3｜完整人协作拓扑示例。实际权限受国家/地区法律、资质和机构规则限制；本表不授予任何执业权限。*

因此 HFWM 需要表示的不是“医生→治疗师→教练”的固定线性流程，而是一个受治理的动态路由问题：当前谁应该主导，谁需要补充证据，谁可以执行什么行动，交接时到底要回答什么问题，什么条件下某个专业重新进入，以及什么时候这个人可以回到自我管理或低频维护。

# 11. 证据、不确定性与判断

一个完整人的世界模型不能把所有信息当成同等权威。HFWM 必须区分人体真实状态、本人报告或专业观察、测量结果、专业解释、模型假设、预测结果和已经确认的行动。缺失证据不能自动当作否定事实；表现不能直接推出唯一原因；异常测试不能直接等于当前主限制因素；行动以后变好可以提高某个假设的支持度，但不能倒推证明唯一病因[3]。

因此系统需要证据条件下的信念状态，而不是强迫确定结论。在现阶段，相比随意生成百分比，使用“支持、削弱、矛盾、未评估、证据不足、无法确定”等受治理状态更符合科学边界，除非未来有足够校准数据。未知本身就是合法输出。

评估属于信息获取行动。评估的价值不在于项目越多越专业，而在于它能否区分当前仍然成立的竞争性解释并改变下一步行动。因此 HFWM 更适合“最小充分评估”，而不是无目的地增加测试。

# 12. 受治理行动选择与责任路由

HFWM 的行动空间远大于“治疗建议”。合法候选行动包括直接解释、观察、等待、补证据、评估、复评、环境调整、降低任务要求、辅助、自我管理、恢复支持、医学升级、专业转介、物理治疗、作业治疗、言语语言或听力服务、心理支持、营养支持、运动进阶、长期维护、暂停、停止和监控。

一个行动只有在满足该行动所需的证据阈值、安全、知情与同意、专业权限、执业范围、现实可行性、停止条件和复评要求时才可以进入。证据不足时，低风险的信息获取行动反而可能比高后果干预更合适。这是 HFWM 的重要安全属性。

对于出院患者，这形成了一个明确的连续责任功能。出院只结束某一个医学住院阶段，不结束这个人的世界模型。系统可以区分：仍需要医学重新评估的状态，适合物理治疗或作业治疗的状态，需要言语语言治疗师/言语语言病理学家或听力师进入的状态，营养或心理因素已经成为重要限制的状态，以及已经适合长期运动、自我管理和维护的状态。

# 13. 纵向状态转移与模型更新

HFWM 只有能够表示“变化”，才真正超过静态本体。设 X_t 表示完整人的真实状态，T_t 表示当前内部/外部任务集合，D_t 表示需求，e_t 表示 Actual Engagement Process（实际调用过程），u_t 表示受治理行动或干预，K_t 表示环境与条件，H_t 表示历史，ω_t 表示未观测扰动。实际调用与行动在类型上必须分开。可用下面的抽象式表示真实状态变化：

**X_{t+1} = F(X_t, T_t, D_t, e_t, u_t, K_t, H_t, ω_t)**

这个式子是架构表达，不是宣称存在一条已经校准的万能人体方程。真实的人可以发生变化但没有被测到；模型也可能因为新证据纠正了旧判断而发生变化，即使人的真实状态本身没有变化。因此 HFWM 必须把“人的真实变化”和“模型表示更新”分开。

**M_{t+1} = B(M_t, Y_{t+1}, E_{t+1}, provenance, ruleVersion)**

历史状态必须可回放。新的证据可以支持、削弱、推翻或仍然无法确定之前的判断，但合法的纵向模型不能用今天的新解释悄悄覆盖过去。

当前框架已经可以定义受治理的状态表示、证据约束推理、行动路由、反馈、复评和纵向更新；经过定量校准的未来状态预测、多步 rollout、因果反事实模拟和自动最优规划仍然属于需要额外实证验证的后续研究能力。
