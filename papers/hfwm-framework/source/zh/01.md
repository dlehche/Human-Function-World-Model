# 摘要

人体相关知识通常按器官、疾病、生理过程、任务、专业、干预和数据系统分别组织，但这些现象始终发生在同一个持续变化的人身上。本文提出人体功能世界模型（Human Function World Model，HFWM）：一种以人体功能为统一组织坐标、在连续时间中持续表示同一个完整人的世界模型框架。人体功能保持 UOHF 根定义，即身体为满足内部和外部需求而能够被适当调用的能力。HFWM 严格区分 Demand、所需人体功能能力、当前能力、Actual Engagement Process、观察反应、带证据的断言与推断、受治理行动以及纵向更新。受治理的内部/外部任务表示用于使 Demand 明确，而不替代 Demand；疾病、损伤、感染、手术和人体自身状态变化可以触发防御、调节、修复、恢复和适应等内部任务，但它们本身不是任务。当前公开 UOHF 能力坐标系包含 18 项核心人体功能能力和 104 项具体能力。受治理的 Functional Bridge 知识关系层把这些能力连接到 Human Reference Atlas 与 NIH Whole Person Reference Physiome 等解剖和生理参考知识，同时保持一般知识与个体证据的边界。HFWM 还支持医学—人体功能双向推理、动态专业与生活协作、受治理的报告投影以及保留历史的状态更新。形式化需求追踪和代表性能力案例表明，该架构已经明确承载状态、观察、记忆、不确定性、行动条件化、责任路由与更新；经校准的未来状态预测和因果反事实规划仍属于后续经验研究目标。

# 历史背景与范围说明

“人体功能世界模型（HFWM）”这一术语已由同一作者于 2026 年 7 月 15 日在 UOHF Definition 2.0 中公开披露。该文明确区分 UOHF、Individual Human Function Model 与 HFWM，并把 HFWM 描述为包含时间、行动、状态转移、预测与记忆回写的世界模型层[11]；UOHF Definition 2.1 随后把人体功能根定义推广到内部与外部需求并延续这一发展[1]。2026 年 8 月 29 日完成的一次定向公开检索使用“Human Function World Model”“world model of human function”“human functional world model”等精确及近似术语，未发现更早由其他团队独立公开、且具有同等组织范围的专门框架。这一文献观察是暂定的，也不作为 HFWM 科学有效性的证据；如果未来发现更早的等价工作，应相应修订历史记录。

# 1. 引言

现代人体知识非常丰富，但在人真正进入不同专业系统时仍然高度分散。解剖学描述结构，生理学描述生命维持与调节过程，医学处理疾病、损伤、病理机制和安全风险，物理治疗与作业治疗在各自专业范围内帮助恢复活动与参与，言语语言与听力专业处理沟通、吞咽和听觉相关问题，心理学与心理治疗处理心理和行为条件，营养学处理物质与能量条件，运动科学发展能力、耐受、技能和表现。这些知识都不可替代，但它们不会自动保证在面对同一个人时仍然使用同一个持续计算对象。

现实中的人并不会按照专业边界被拆开。感染、循环、睡眠、步行、认知、情绪、吞咽、工作、照护家庭、恢复和运动都发生在同一个生命体中。如果模型在每次专业切换时都更换根对象，那么所谓“完整的人”最终仍然只是多个记录系统的拼接，而不是一个连续的人体世界模型。

HFWM 的起点不同：无论处于生理变化、疾病与损伤、现实生活、专业干预、家庭与环境还是不同时间点，同一个完整的人始终是持续建模主体。人体功能提供统一运行坐标。模型不只问“有什么病”“哪个指标异常”，还要持续回答：这个人此刻必须完成什么，相关需求是什么，需要哪些人体功能，当前有哪些能力，这些能力实际如何发挥，付出了什么代价，边界在哪里，证据支持到什么程度，下一步什么行动最合适、该由谁进入，以及行动以后这个人发生了什么变化。

这种视角也重新定义了疾病后的恢复。疾病或损伤以后，人体并不是被动等待生理指标回归，而是在主动满足一组内部生物学目标。在存在相应受治理任务身份与触发规则时，HFWM 可以通过防御、止血、调节、组织修复、稳态恢复、恢复与适应等内部任务来表示这一过程；与此同时，这个人还需要逐步恢复穿衣、进食、交流、移动、工作、照护家庭和运动等外部任务。完整人的世界模型必须同时表示这两条任务链。

因此，本文不是再写一篇 UOHF 本体论文，也不是重新列人体功能清单。UOHF 已经提供语义和形式化基础[1-4]。UOHF Definition 2.0 已明确区分 UOHF、Individual Human Function Model 与 HFWM，并把 HFWM 定义为加入时间、行动、状态转移、预测与记忆回写的世界模型层[11]；Definition 2.1 随后把人体功能根语义推广到内部与外部需求[1]。本文把这条既有发展轨迹集中展开为独立的人体功能世界模型框架，定义其持续建模对象、状态、运行任务结构、动态变化、行动空间、专业与生活协作和面向人的报告投影，并给出初步形式一致性评估以及明确的后续经验验证目标。

# 2. 目标、方法与范围

## 2.1 目标

本文目标是定义一个具有科学可辩护性的最低人体功能世界模型架构：同一个完整的人，在生物、生理、医学、人体功能、行为、环境、专业服务和连续时间中始终是同一建模主体。

## 2.2 方法

本文采用概念分析、类型分离、形式化建模、能力问题设计、与两项重要完整人计划的定位比较、案例推演、形式一致性分析、失败条件分析以及实现边界分析。内容承接已公开 UOHF 定义与形式框架[1-4]，但不公开生产提示词、模型上下文组装、数据库结构、私有检索与重排规则、完整关系拓扑、商业运行阈值及其他与学术验证无关的商业实现细节。

## 2.3 范围

HFWM 是完整人的世界模型框架，但“完整的人”不等于已经穷尽模拟每一个分子、细胞、器官、行为和社会变量。“完整”指的是无论信息来自哪个尺度或专业，持续主体始终是同一个人；所有相关知识都可以被放回这个人，而不会因为专业切换而更换根身份。追求的是可扩展的表示闭合和明确的未知，不是全知。

# 3. 与完整人计划的定位关系

## 3.1 NIH Whole Person Reference Physiome（WPP）

美国国立卫生研究院（NIH）已启动 Whole Person Reference Physiome 计划，目标是建立健康生理功能的整合知识网络，并逐步形成可交互的完整人健康模型[5]。相关研究与协调中心提出建立健康男性和女性身体的整合地图，并将其转化为用于分析临床数据的模型[6]。HFWM 将 WPP 视为重要互补基础，而不是竞争对象。WPP 越能够提供跨器官、跨尺度的生理模型，HFWM 越能够用这些模型约束或解释完整人状态、功能能力、内源调节和恢复。

两者的区别主要在组织问题。WPP 以完整人生理整合和健康生理功能为中心；HFWM 以同一个人如何完成内部和外部任务为中心，进一步显式连接需求、所需能力、当前能力、实际功能调用、证据、专业/生活行动和纵向更新。未来 HFWM 完全可以直接接入与 WPP 兼容的生理模型，而不把生理变化排除在人体功能世界之外。

## 3.2 欧洲 Virtual Human Twins（VHT）

欧洲委员会将 Virtual Human Twin 定义为人体健康或疾病状态的数字表示，可覆盖细胞、组织、器官或器官系统等不同尺度，并通过软件模型和数据模拟与预测其现实对应物的行为[7]。EDITH 路线图进一步提出多尺度、多时间、多学科的整合 VHT 愿景，面向个体化、预测性和参与式医疗[8,9]。

HFWM 与这一路线兼容，但采用不同的组织中心。VHT 可以围绕健康/疾病状态和病理生理模型建立；HFWM 则要求这些状态继续绑定到这个人的内部/外部任务表示、所需人体功能能力、实际调用过程及其带证据的功能调用断言、证据状态、功能边界、专业与生活协作、下一步行动和纵向回写。VHT 因此可以成为 HFWM 中极具价值的模型组件，而 HFWM 提供跨专业、跨生活场景的任务—功能—行动接口。

本文不通过贬低 WPP 或 VHT 来证明 HFWM 的价值。它们解决的是不同但相互重叠的完整人建模问题。HFWM 所补充的是：把跨尺度生物学模型继续连接到同一个人“必须做什么、能做什么、实际怎么做、下一步该做什么以及后来发生了什么”。
