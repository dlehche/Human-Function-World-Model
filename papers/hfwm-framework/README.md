# The Human Function World Model

## Modeling the Whole Person Through Human Function Across Tasks, States, Actions, and Longitudinal Change

**Author:** Lei Che  
**Affiliation:** MoveTips Technology (Beijing) Co., Ltd.  
**Status:** manuscript / preprint pending archival record  
**License:** CC BY-NC 4.0

This is the first dedicated full-length HFWM framework manuscript in the author's publication lineage. Earlier UOHF Definition 2.0 and 2.1 records contain the public historical roots of HFWM.

The manuscript defines:

- the same whole person as the persistent modeled entity;
- human function as the organizing coordinate, not the modeled-world boundary;
- internal/external task → Demand → Required Capacity → Current Capacity → Actual Engagement;
- the public 18-core/104-specific capacity coordinate;
- Functional Bridge as a governed knowledge-relation layer;
- HRA and WPP as external scientific reference resources with preserved provenance boundaries;
- medicine–human-function bidirectional reasoning;
- professional, caregiving and environmental coordination;
- evidence-constrained action and longitudinal update;
- governed human-readable report projection;
- world-model requirements, competency cases, falsifiability and empirical research boundaries.

The complete production reasoning system is not published here.
