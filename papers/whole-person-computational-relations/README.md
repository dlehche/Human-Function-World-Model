## Research question / 研究问题

How can heterogeneous evidence from medicine, physiology, rehabilitation, exercise, nutrition, psychology, behavior and environment form **verifiable computational relations about the same continuing person**, without conflating native domain observations, scientific reference knowledge, evidence-qualified functional capacity, actual functional engagement or professional decisions?

不同专业领域的事实如何在保留医学、生理、康复、运动、营养、心理、行为与环境原生含义的前提下，围绕**同一个持续存在的人**形成可执行、可追溯、可验证、可修订的计算关系？

## Contribution and scientific boundary / 研究贡献与边界

- Proposes typed, source-preserving cross-domain relation records and question-specific evidence-qualification gates.
- Keeps general scientific knowledge, mapping assertions, person-specific evidence, capacity estimates, actual-engagement judgments and authorized actions distinct.
- Preserves the HFWM composition, computational coupling, evidence-derivation and task–capacity explanation graph roles.
- Specifies reference-execution contracts, constructed competency/counterexample fixtures and prospective strong-baseline comparisons.
- Uses UOHF as the semantic authority and HFWM as the whole-person computational framework; does not replace either canonical foundation.

**Not established:** an independently executed cross-disciplinary benchmark; observed superiority to equally informed strong baselines; calibrated clinical prediction; causal intervention benefit; a production-ready whole-person simulation; or peer-reviewed acceptance.

本文提出有类型的跨领域关系与证据资格合同，保留能力与实际调用、一般知识与个体事实、认识更新与人体真实变化之间的区别，并设计了可反驳的计算验证。**它尚未证明独立跨领域实测优势、临床预测效果或干预因果效应。**
