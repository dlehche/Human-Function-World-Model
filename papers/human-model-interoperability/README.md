## What this paper contributes

This paper proposes **human function as a common computational coordinate for interoperable whole-person models**. Heterogeneous medical, physiological, psychological, cognitive, movement, nutritional, behavioral, environmental, device, and AI models can retain their native meanings while contributing to a shared interpretation of the same person.

The proposed architecture makes explicit the relation among:

**task and demand → evidence-supported capacity → actual functional engagement → performance / cost / boundary / recovery → evidence-qualified interpretation → action and longitudinal update**

UOHF supplies semantic identities and governed relations. HFWM supplies the person-bound computational architecture for coordinating model contributions over time. Domain models retain their own mathematics, assumptions, uncertainty, validation scope, and professional meaning.

## Position in the HFWM research program

This is a **focused interoperability paper**. It does not replace:

- **UOHF Definition 2.1**, the current authoritative overall UOHF framework;
- **The Human Function World Model V1.0**, the dedicated HFWM architecture publication;
- the **UOHF Human Function Capacity System V1.0**, the 18-core/104-specific capacity catalogue; or
- the focused UOHF formal framework.

Instead, it develops the cross-model interoperability question: how heterogeneous models can contribute to the same continuing person without being collapsed into one universal model or one scalar score.

## Claim boundary

The paper presents a conceptual computational architecture, traceable hypothetical cases, and an evaluation agenda. It does **not** claim universal compatibility of arbitrary models, completed empirical calibration of all human-function capacities, demonstrated clinical benefit, autonomous diagnosis or treatment, or validation of every external model mapping.
