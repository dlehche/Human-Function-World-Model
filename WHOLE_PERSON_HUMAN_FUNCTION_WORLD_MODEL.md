# Whole-Person Human Function World Model / “完整的人”人体功能世界模型

## Canonical statement / 核心定义

**English:** The Human Function World Model (HFWM), built on the Unified Ontology of Human Function (UOHF), uses **the same whole person as the persistent modeling object** across medical care, rehabilitation, exercise, nutrition, psychology, everyday life, and longitudinal change.

**中文：** 人体功能世界模型（HFWM）基于人体功能统一本体（UOHF），以**同一个“完整的人”作为持续建模对象**，持续连接就医、康复、运动、营养、心理、日常生活与长期身体变化。

> **The whole person is the modeling object.**  
> **“完整的人”是持续建模对象。**

---

## What “whole person” means here / 这里的“完整的人”是什么意思

“完整的人”并不表示模型已经知道一个人的全部信息，也不表示把不同专业混成一种数据。

它表示：无论一个人处于就医、康复、运动、饮食、心理变化或日常生活场景，模型持续跟踪的对象始终是**同一个人**。疾病仍然是疾病，影像仍然是影像，训练仍然是训练，心理与生活事实也保留各自含义；UOHF 提供统一的人体功能语义，使这些事实能够围绕同一个人的人体功能状态建立可追溯关系。

“Whole person” does not mean that the model knows everything about a person, nor that distinct professional domains are collapsed into one undifferentiated dataset.

It means that the modeled subject does not change when the context changes. Medical care, rehabilitation, exercise, nutrition, psychology, and everyday life are represented around **the same person over time**, while each domain retains its own professional meaning and boundary.

---

## Why human function is the organizing coordinate / 为什么以人体功能作为组织坐标

UOHF defines human function as:

> **Human function is the body's capacity to be appropriately engaged to meet internal and external demands.**

> **人体功能，就是身体被正常调用的能力。**

The Human Function World Model uses human function as the organizing invariant across:

**task and demand → required capacities → current capacity → actual functional engagement → evidence → cost / boundary / reserve / recovery → human-function state → action → feedback → longitudinal update**

人体功能世界模型围绕：

**任务与需求 → 所需能力 → 当前能力 → 实际功能调用 → 证据 → 代价 / 边界 / 储备 / 恢复 → 人体功能状态 → 行动 → 反馈 → 长期更新**

持续表示同一个人。

## MoveTips product implementation / 木梯产品实现

MoveTips Human Function is the product implementation of this whole-person human-function modeling direction.

It connects medical care, rehabilitation, exercise, nutrition, psychology, and everyday bodily change through longitudinal human-function reporting and continued model updates.

木梯人体功能通过身体功能报告，把就医、康复、运动、营养、心理与日常身体变化持续连接到同一个人的人体功能状态中，不只记录发生了什么，也尝试解释：

> **为什么这些变化最终在这个人身上形成了当前问题。**
