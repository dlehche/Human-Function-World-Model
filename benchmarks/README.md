# HFWM Public Evaluation and Benchmarks

This directory is reserved for public, reproducible evaluation artifacts.

Potential benchmark dimensions include:

- internal/external task identification;
- Demand traceability;
- internal-task trigger discipline;
- required-capacity traceability;
- capacity/engagement type separation;
- evidence sufficiency and uncertainty handling;
- unsupported-diagnosis avoidance;
- safety escalation;
- professional responsibility routing;
- longitudinal update consistency;
- history preservation;
- report-state consistency;
- future state-transition prediction when empirically supported.

A benchmark must not expose private production decision rules merely to demonstrate performance.

## Evaluation levels

1. semantic/type conformance;
2. formal requirements traceability;
3. competency cases;
4. deterministic runtime conformance where publicly reproducible;
5. longitudinal empirical validation;
6. calibrated future-state prediction;
7. causal/counterfactual validation where scientifically justified.

## Related prospective evaluation protocol

The [verifiable whole-person computational-relations preprint](../papers/whole-person-computational-relations/README.md) (DOI: [10.5281/zenodo.23922582](https://doi.org/10.5281/zenodo.23922582)) specifies proposed relation-qualification checks, finite competency cases, source-dependency revision tests and strong-baseline evaluation design. **This link does not mean the public benchmark or independent performance results have been implemented or released.**

## Related temporal-state and prediction protocol

The [temporal whole-person state and future prediction methods preprint](../papers/whole-person-state-prediction/README.md) (DOI [10.5281/zenodo.23934150](https://doi.org/10.5281/zenodo.23934150)) proposes tests separating event time from evidence availability, conditional observed-policy forecasts from intervention effects, and real longitudinal prediction scores from synthetic engineering conformance. **These are future evaluations, not an already executed predictive benchmark.**
